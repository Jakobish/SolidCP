## 🎨 UI Components - Usage Guide

### Most Used Components

```razor
<!-- Card Container -->
<UiCard Title="Page Title" Description="Optional description">
    <ChildContent>
        <!-- Your content here -->
    </ChildContent>
</UiCard>

<!-- Form Input -->
<UiInput Label="Field Label" 
         @bind-Value="model.Property" 
         Required="true"
         Placeholder="Help text" />

<!-- Button -->
<UiButton Variant="primary" OnClick="HandleClick">Click Me</UiButton>
<UiButton Variant="secondary" OnClick="NavigateBack">Cancel</UiButton>
<UiButton Variant="danger" OnClick="Delete">Delete</UiButton>

<!-- Loading State -->
<UiButton IsLoading="@isSaving" Type="submit">Save</UiButton>

<!-- Notifications -->
@inject NotificationService NotificationService

await NotificationService.ShowSuccess("Operation completed successfully");
await NotificationService.ShowError("Something went wrong");
```

### Styling Guidelines

- **Always use Tailwind classes**: `class="grid grid-cols-1 md:grid-cols-2 gap-6"`
- **Dark mode support**: Add `dark:` variants like `dark:text-gray-100`
- **Responsive design**: Use `md:` prefixes for desktop layouts
- **Consistent spacing**: Use Tailwind spacing utilities

## 🚨 Common Issues & Solutions

### Build Errors

**Problem**: Type not found errors
**Solution**: Add proper `@using` directives at top of .razor files

**Problem**: Component property errors
**Solution**: Check existing components in `Components/` directory for correct parameter names

### Runtime Errors

**Problem**: Service injection failures
**Solution**: Register service in `Program.cs` with `builder.Services.AddScoped<ISpaceService, SpaceService>();`

**Problem**: Navigation issues
**Solution**: Use `@inject NavigationManager Navigation` and `Navigation.NavigateTo("/spaces");`

### UI Issues

**Problem**: Dark mode not working
**Solution**: Always include `dark:` variants for all custom classes

**Problem**: Responsive layout broken
**Solution**: Follow Tailwind responsive prefixes: `sm:`, `md:`, `lg:`
